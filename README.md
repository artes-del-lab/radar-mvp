# РАДАР — MVP

Система раннего обнаружения тендеров на спецтехнику (Caterpillar, Komatsu,
Hitachi, John Deere). Полный цикл прототипа:

**найденный тендер → оценка релевантности (Claude) → черновик первого сообщения ЛПР**

Система ничего не отправляет сама — только готовит черновик для менеджера.
Бриф: [`docs/radar-project-brief.md`](docs/radar-project-brief.md).

## Структура

```
radar-mvp/
├── backend/                 # Python + FastAPI: логика и API для дашборда
│   ├── app/
│   │   ├── config.py        # чтение ключей из .env, выбор mock/реальных данных
│   │   ├── llm.py           # общий вызов Claude (JSON-ответ) и кэш
│   │   ├── criteria.py      # критерии отбора: коды ОКПД2 (28.92, 28.30, 29.10 без легковых и автобусов)
│   │   ├── models.py        # единый формат тендера внутри системы
│   │   ├── outreach.py      # черновик первого письма ЛПР (без отправки)
│   │   ├── scoring.py       # оценка релевантности: предфильтр + Claude, кэш
│   │   └── tenderplan_client.py  # получение тендеров: Тендерплан или mock
│   └── requirements.txt     # зависимости Python
├── frontend/                # дашборд (HTML/JS, без сборки)
├── data/
│   ├── mock_tenders.json    # тестовые тендеры

└── README.md
```

## Ключи API

```bash
cp .env.example .env
```

В `.env` впишите:

- `ANTHROPIC_API_KEY` — нужен для оценки и черновиков;
- `TENDERPLAN_API_KEY` — пока можно оставить пустым: без него система берёт
  тендеры из `data/mock_tenders.json`.

### Как переключиться на реальные данные Тендерплана

1. В личном кабинете Тендерплана создайте ключ поиска (слова «экскаватор»,
   «бульдозер», «погрузчик», «кран», бренды и коды ОКПД2 28.92, 28.30, 29.10).
2. Там же выпустите API-токен и впишите его в `TENDERPLAN_API_KEY`.
3. Если ключей поиска несколько — впишите ID нужного в `TENDERPLAN_SEARCH_KEY_ID`.
4. Перезапустите бэкенд. Пустой `TENDERPLAN_API_KEY` — снова тестовые данные.

### Оценка и черновики из консоли

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.scoring          # оценить все тендеры (результаты кэшируются)
python -m app.scoring --force  # переоценить заново
python -m app.outreach TND-001 # черновик письма по тендеру (--force — новый вариант)
```

Полные команды запуска появятся на шаге 7, когда будут готовы бэкенд и дашборд.
