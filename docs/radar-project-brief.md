# РАДАР — техническое задание на MVP

> Текст перенесён из исходного PDF-брифа, чтобы он лежал рядом с кодом.

## Концепция

РАДАР — система раннего обнаружения сделок для компании Евгения (эксклюзивный
представитель немецкого поставщика спецтехники — John Deere, Caterpillar,
Komatsu, Hitachi и др. на российском и смежных рынках).

Не позиционируется как «парсер тендеров», а как инструмент, который:

1. Находит релевантные тендеры по спецтехнике раньше конкурентов.
2. Оценивает каждый лот — стоит ли в него заходить, с человекочитаемым обоснованием.
3. Готовит первое касание — персонализированный черновик сообщения ЛПР
   (лицу, принимающему решение) по конкретному лоту.

Дальнейшая коммуникация с клиентом (реальные продажи, звонки, переговоры) — на
живом менеджере. Система не отправляет сообщения автоматически, только готовит
черновик.

## Формат MVP

Демо-версия для презентации Евгению — не боевая система, а рабочий прототип
ключевой логики на ограниченном масштабе:

- одна тендерная площадка / источник данных (не всё покрытие рынка);
- логика фильтрации и оценки через LLM API;
- простой презентабельный интерфейс/дашборд (не сырой код в терминале);
- 2–3 реальных тестовых примера, отработанных end-to-end.

## Источник данных

Тендерплан (https://tenderplan.ru/rates) — агрегатор тендеров с 180+ площадок,
открытый API включён в тариф. Подключение:

1. Регистрация + 14-дневный триал.
2. Получение API-ключа в личном кабинете.
3. Перед оплатой платного тарифа — подтвердить у поддержки, что конкретный
   выбранный тариф включает API-доступ.

Альтернатива, если Тендерплан не подойдёт по данным: прямая интеграция с ЕИС
zakupki.gov.ru через SOAP веб-сервис и токен физлица — технически сложнее,
доступ к старому бесплатному FTP закрыт с 01.01.2025.

## Критерии релевантности лота (черновые, до уточнения с Евгением)

- Код ОКПД2: группа 28.92 (машины для горных работ и строительства), 29.10 (тракторы).
- НМЦК — отсекать лоты ниже разумного порога.
- Регион поставки — под географию работы компании.
- Срок подачи заявки — приоритет свежим лотам с открытым окном.
- Ключевые слова: бренды (John Deere, Caterpillar, Komatsu, Hitachi) + типы
  техники (экскаватор, бульдозер, кран, погрузчик).

## Что MVP должен продемонстрировать на созвоне с Евгением

Связка из трёх шагов на 2–3 реальных примерах:

1. Найденный тендер (откуда взят, когда опубликован).
2. Оценка релевантности с человекочитаемым обоснованием.
3. Готовый черновик первого сообщения ЛПР по этому лоту.

## Технический стек (черновой)

- Получение данных: Tenderplan API.
- Логика оценки и генерации черновика: LLM API (через код).
- Интерфейс: простой веб-дашборд.
- Хостинг: бесплатный/дешёвый тариф (Vercel, Railway или аналог) — демо-нагрузка минимальна.

## Ограничения MVP (проговорить с Евгением как «что дальше за бюджет»)

- Не покрывает весь рынок тендеров — только выбранный источник/площадку.
- Не автоматизирует отправку первого касания — только черновик для менеджера.
- Не обучено на архиве компании — работает на тестовом наборе лотов, не на
  реальных прошлых сделках Евгения.
